SekiroCraft 只狼 × Minecraft — 小白安装教程（2026-10-11）
========================================================
安装器可选 Forge 或 Fabric，Minecraft 都必须为 Java 版 1.20.1。
Forge 使用已游戏测试的 preview.6；Fabric 保留 2026-10-10 已发布版本。
本包不包含血条位置移动或切换键，原生 Boss 血条保持原位置。
已知问题：只狼敌人命中时，MC 人物和方块仍可能闪烁。
本包不含两款游戏、账号、存档、鬼泣、拔刀剑或枪械等第三方玩法模组。

一、先准备游戏和加载器
1. Windows 10/11 64 位；两款游戏都先正常运行一次。
2. 只狼须为已适配的 1.06 程序。安装器自动校验程序指纹。
   同为 1.06 但程序不同也可能不兼容；不能修改哈希绕过检查。
3. 在启动器准备以下一种 MC 实例，推荐开启版本隔离：
   Forge：MC 1.20.1 + Forge 47.4.26（已测试；最低 47.4.10，低于 48）。
          运行时 Java 17。本安装器不负责安装 Forge 加载器。
   Fabric：MC 1.20.1 + Fabric Loader 0.19.5（建议版本）。
           本包内置 Fabric API 0.92.12+1.20.1，保留原已发布桥接版本。
           使用 Java 21，桥接最低 Java 17；兼容性还取决于其它模组依赖。
   Forge 与 Fabric 使用不同的桥接 JAR 和配套只狼 DLL，不要混用。
   Forge 不安装 Fabric API，不安装 Fabric 版桥接或 Fabric 版玩法模组。
4. 实例运行到主菜单后，正常退出两款游戏和启动器，再安装。

二、双击安装，无需 Git / 编译工具 / PowerShell 命令
1. 下载并解压 SekiroCraft-Installer-0.1.0-20261011.zip（一键安装包）。
   双击其中 SekiroCraft-Setup-0.1.0-20261011.exe。
2. “只狼目录”：选择含 sekiro.exe 的文件夹。
   Steam：库 -> 右键只狼 -> 管理 -> 浏览本地文件。
3. “MC 加载器”：默认 Forge；使用 Fabric 的人务必改选 Fabric。
4. “MC 游戏目录”：从启动器打开这个实例的实际游戏目录，选择含 mods
   的文件夹。不要选择启动器 EXE、其它版本目录、saves 或 mods 本身。
   例如 Forge：E:\.minecraft\versions\1.20.1-Forge_47.4.26
   例如 Fabric：E:\.minecraft\versions\1.20.1-Fabric 0.19.5
   关闭版本隔离时目录可能是 .minecraft 根目录；以启动器 gameDir 为准。
   目录名不能证明加载器正确，程序会核对版本 JSON 或首次运行日志。
5. “MC 安装方式”：
   已有实例（Forge / Fabric）：PCL、HMCL、Prism、官方启动器都可用。
   官方启动器新建（仅 Fabric）：先运行原版 1.20.1，选择 .minecraft
   根目录（含 versions、launcher_profiles.json）。安装器建立独立的
   SekiroCraft-1.20.1-Fabric-0.19.5 版本及游戏目录；首次启动需联网补库。
   第三方启动器和 Forge 用户先在启动器准备实例，再选已有实例。
6. 钩索键默认 M。在只狼按键设置里把钩索改成相同字母。
7. 建议保留“Boss 血量耗尽自动扣红点”。完整 MC 忍杀尚未实现；不开启时
   Boss 可能无法用 MC 武器推进阶段。特殊剧情条件和奖励仍需单独验证。
8. 已有只狼模组时默认拒绝覆盖。确认暂时停用旧加载器，才勾选
   “备份并替换”。安装器完整备份旧 DLL/配置，不强制关闭游戏。
9. 点击“检查目录”，确认加载器和目录正确，再点“一键安装 / 更新”。
   程序安装所选加载器的成对 DLL/JAR，移走并备份重复的旧桥接。
   Fabric 同时安装本包 API；Forge 不会安装该 API。
   保留其它模组、options.txt 和 MC 世界；只狼存档仅备份副本，不改写。
10. 权限不足时点“以管理员重试”，重新检查。无需关闭安全软件。
    EXE 未做商业代码签名，只从本项目发布页下载并核对 SHA256SUMS。

三、开启桥接
1. 启动刚安装的 MC 实例，进入独立单人测试世界，建议创造模式虚空世界。
   不要用重要生存存档测试桥接；真实只狼地面由桥接附近采样提供。
2. 启动只狼，进入可以操作人物的场景。
3. 在 MC 按 T 输入 /sekirobridge on 并回车。
4. 切回只狼窗口，等待位置和地面采样。若处于只狼菜单输入，按 F6 返回。
5. 先测试移动、背包、放置方块、F5 下蹲及 M 钩索。

四、常用操作
WASD：移动；空格：跳跃；潜行/疾跑以 MC 键位为准。
E：背包；1-9/滚轮：快捷栏；左/右键：MC 攻击、使用和放置。
F5：第一/第三人称；M（或所选字母）：请求只狼原生钩索。
F6：切换 MC 控制与只狼菜单输入；只狼菜单点不到先按 F6。
F7：诊断；F8：暂停/恢复控制；F9：生成测试草方块。
F1：隐藏/显示 MC HUD；手臂和状态栏不见时先按一次。
R 和鼠标侧键可给其它模组绑定；M、F6-F9 避免与其它动作冲突。
本项目枪械参考配置：开火和瞄准用鼠标中键，R 换弹；安装器不改个人键位。

MC 聊天命令：
/sekirobridge status             查看连接、视角和加载状态
/sekirobridge hud                恢复第一人称手臂与原版状态栏
/sekirobridge stamina off        隐藏桥接姿态条（耐力条）
/sekirobridge stamina on         显示姿态条，设置会保存
/sekirobridge off                临时停止桥接
/sekirobridge performance on     Forge：开启桥接窗口垂直同步优化（默认）
/sekirobridge performance off    Forge：恢复 MC 当前垂直同步选项
性能开关不降低鬼泣特效质量，不改 options.txt；本包不提供 Boss 血条切换键。

五、切换加载器、停用与恢复
1. 每次安装、更新、停用、恢复前，正常退出两款游戏和启动器。
2. 切换 Fabric/Forge 或更换 MC 目录前，先点“恢复安装前状态”，
   再选新加载器与新实例安装；同一个只狼目录同时只能关联一套桥接。
3. “停用桥接”：关闭桥接及自动扣红点，下次启动只狼生效。
   正常玩只狼务必停用；MC JAR 保留，再次安装可启用。
4. “恢复安装前状态”：还原首次安装前 DLL/配置/MC 模组，移除本次新增文件。
   若之前已有其它桥接，恢复后就是那个旧状态，未必是纯原版。
   新世界、其它模组与个人按键保留；运行时改变的 MC 界面偏好保留。
5. 备份在只狼目录 .sekirocraft-installer 中，恢复前不要删除或移动它。
   该程序不自动恢复存档。安装后自行改动 DLL/JAR 会触发保护，需先备份
   并恢复对应安装文件再重试。旧安装脚本与新安装器不要交替更新。

六、常见问题
加载器/版本不对：确认所选 Forge 或 Fabric 对应 1.20.1，运行一次退出，
                 再从启动器打开真正的游戏目录。Forge 里不要放 Fabric API。
游戏未退出：正常退出两款游戏、启动器及 Java/Gradle，程序不会强制结束它们。
程序指纹不支持：反馈只狼版本，不要下载陌生游戏 EXE 或修改哈希。
连接失败：同一个 Windows 用户会话；MC 单人世界与只狼可操作场景都已进入；
          两端 DLL/JAR 配套；执行 on 后用 status 或 F7 查看状态。
背包/菜单点不到：检查 F6 输入归属与 F8 是否暂停。
受击闪烁：当前已知问题，尚未完全修复。
鬼泣特效/黑屏：Forge preview.6 已修复已核对的 VIX/AAA 路径；其它版本或
               渲染组合需另行验证。保留原模组，提供版本及最短复现步骤。
官方新建 Fabric 首次启动失败：联网补齐库，检查 Java；也可先用 Fabric
                              官方安装器准备好，再选已有实例。
