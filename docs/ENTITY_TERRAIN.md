# 0.1.1 生物地形碰撞

Fabric 0.1.1 与 Forge 0.1.1-forge-preview.7 同步此修复。两种加载器均由用户于 2026-10-11 实机验收后授权发布。

此前非玩家实体依赖玩家周围、以玩家高度起始的地面射线；未知地面仅等待 500 毫秒。坡地、高低平台或实体超出玩家采样区时，生物可能继续掉入桥接世界的空处。

现在 MC 生物、点燃的 TNT、掉落物和下落方块按自身足底高度向只狼查询地面，检查一次移动覆盖的全部水平采样格。集成服务器维护结果，客户端使用相同碰撞层；上下平台不共享玩家的地面高度。未知结果暂停移动并重试，确认没有地面的射线允许正常下落，原版 MC 方块碰撞保留。场景加载期间暂停附近实体，恢复后重新采样；仅修正浅层地面侵入，不把已经落入地下的旧生物强行传回。

查询范围为玩家附近 48 个原生单位；最多维护 256 个实体、每个足底范围 256 个格子。全局最多 48 个生物地面查询并发，每 50 毫秒最多发送 32 条，每个实体每轮最多新增 16 条；常规地面 500 毫秒刷新，观测最长保留 1500 毫秒。缺少响应保持等待，不将超时当成悬崖。这些限制控制查询成本，不代表整张地图的碰撞网格；复杂悬空结构、薄栏杆、陡壁与极大生物仍可能需要定向适配。原生只狼 NPC 的方块碰撞和寻路不属于本次修复。

## 更新与测试

推荐下载 `SekiroCraft-Installer-0.1.1-20261011.zip`，解压双击 EXE，选择当前加载器及实例，先检查再更新。必须先正常退出两款游戏和启动器。不要混用旧脚本更新器与一键安装器；更换加载器或实例前先恢复旧安装。

手动部署分别下载 `SekiroCraft-Fabric-1.20.1-0.1.1.zip` 或 `SekiroCraft-Forge-1.20.1-0.1.1.zip`：

1. 退出两款游戏，备份只狼目录 DLL/配置和旧 MC 桥接 JAR。
2. 将对应的新桥接 JAR 放入实例 `mods`，将所有旧的同 ID 桥接 JAR 移到 `mods` 之外，避免重复版本。Fabric 需要 Fabric API 0.92.12+1.20.1；Forge 不安装 Fabric API。
3. 本轮两个包复用已发布的 preview.6 原生核心 DLL（SHA256 `00368afc9073e42fe3ea2b73bc919f1789b9a51f6ffd5dd81ead2a2ac074ae92`）。若当前 DLL 已是该文件，只更新 JAR 即可；否则使用所下载包的配套 DLL。保留原配置；首次安装才复制默认 INI。默认配置的自动扣红点为关闭，MC 战斗建议自行开启 `native_hits=1` 和 `auto_boss_phases=1`，正常玩只狼前关闭。
4. 进入单人测试世界及只狼可操作场景，执行 `/sekirobridge on`。在年轻一心场景、高低平台、坡地和台阶上重新放生物，观察行走、击退及加载后恢复。真实悬崖仍会掉落。

发布包不包含本地 Boss 血条位置预览、游戏本体、存档或第三方玩法模组。受击特效导致 MC 人物/方块闪烁仍待修复；本轮不能视为该问题已解决。
