# 本轮更新与验收

更新只狼 DLL、Minecraft JAR 和 JNI，两款游戏需先退出。原创仓库不参与本轮代码修改。

| 问题 | 本轮实现 | 验收方式 |
| --- | --- | --- |
| 两个人物重叠 | 清除玩家 ChrIns 的 Draw 位，停止使用 AI 隐身标志；断线恢复 | 桥接后观察只剩 MC 模型，F7 中 `Native hero hidden=yes`；关闭桥接后狼恢复 |
| 钩锁等按键冲突 | I/O/J 转为 MC 背包/丢弃/换手，E/Q/F 留给只狼 | F8 开启时仍可按原设置用钩锁；F8 关闭时恢复只狼鼠标战斗操作 |
| 走跑无动画 | 根据只狼实际位置变化计算 MC 肢体速度与身体朝向 | 走、跑、侧移、停下，观察腿部动作与方向；这不等于骨骼战斗动画移植 |
| 背包无鼠标 | 在最终 HUD 层绘制软件光标并转接位置/点击 | I 打开背包，选物品、搜索、Shift 转移，Esc/I 关闭后可正常转镜头 |
| 右键无法放置 | 准星射线改从实际桥接相机出发，同时保留原版物品放置逻辑 | F9 生成起始草方块，准星指向它，选一个方块物品后右键在邻面放置 |
| 创造不能飞 | F6 切换飞行；仅创造模式，匹配原生位置更新/计时器后启用 | F7 查看飞行 available、player callbacks 增长；F8 开启后 F6、Space/Shift，F6 落回地面 |
| 玩家穿 MC 方块 | 原生最终位置写入前，以 MC 方块 VoxelShape 约束玩家包围盒 | 方块墙、跳上方块、天花板、半砖；F7 `corrections` 应增长；属于实验玩家约束 |
| 第一人称 | 尚未完成原生相机控制 | 本版保持第三人称，MC F5 不代表只狼画面也变为第一人称 |

进入 MC 的专用单人创造世界，执行 `/sekirobridge on`，再进入只狼可活动场景。只狼 F7 为诊断菜单，F8 为 MC 操作开关，F9 生成起始草方块。首次测试应先确认角色、背包、准星放置，再测试飞行与碰撞。

地面移动时 Shift 留给只狼跑步，MC 潜行/贴着箱子放置改用 Alt；背包内的 Shift 快速转移仍用 Shift。飞行时 Shift 下降。

`player callbacks` 始终为 0 或 hook waiting 表示原生移动接口未匹配，本版不会按猜测写坐标。测试期间若飞行/碰撞异常，可在 F7 关闭 `Enable experimental player collision / flight`；若游戏无法保持运行，退出后在只狼 `sekirobridge.ini` 设置 `player_features=0` 再启动。该开关禁用角色控制，不移除 MC 世界。

玩家碰撞未创建 Havok 物体，NPC 和钩锁不会因此碰撞 MC 方块。原生地面没有转换到 MC 中，所以右键需对着已有 MC 方块操作，F9 是起始方块入口。第一人称、原生地形采样、敌人物理和跨游戏伤害仍需后续原生适配。

日志中新增 `heroHidden`、`moveHook`、`playerCalls`、`constrained`、`flying`。这些说明接口状态，不替代实际游戏验收。全部构建和夹具均不启动游戏。
