# MC 主导人物与相机：mc-owner2-renderfix1

这是配套的只狼 DLL + MC JAR/JNI 更新。两款游戏正常退出后一起替换。原创仓库及存档保持独立。本版没有由助手启动游戏做实机测试。

`renderfix1` 仅改只狼 DLL，兼容已安装的 `mc-owner2` JAR。针对新版本实测的全不可见问题，移除无关绘制任务对整帧的全局否决，保存已执行场景深度副本，并独立绘制 HUD。重启只狼即可加载 DLL；MC 无须因此退出。

本次修复背包快点偶发失效、原生地面右键不能放置、斜坡刷新导致浅穿地，以及移动时旧 MC 图像配上新相机。另结合 SkyCraft 加入地形就绪门控；请先验证以下项目，再继续大范围游玩。

## 操作方式

在专用 Minecraft 单人创造世界输入 `/sekirobridge on`，切回只狼可活动场景。默认第一人称；启用桥接后按 MC 的键位操作。

| 操作 | 默认按键 |
| --- | --- |
| 移动 / 跳跃 | WASD / Space |
| 潜行 / 疾跑 | Shift / Ctrl |
| 创造飞行 | 双击 Space；Space 上升，Shift 下降 |
| 背包 / 丢弃 / 换手 | E / Q / F |
| 第一人称与两个第三人称 | F5 |
| 挖掘、攻击 MC 生物 / 放置、使用 | 左键 / 右键 |
| 选物品 | 1–9 / 滚轮 |
| 桥接诊断 / 暂停 MC 输入 / 起始草方块 | F7 / F8 / F9 |

I/O/J、Alt 潜行和 F6 飞行已由 MC 默认逻辑替代。F7/F8/F9 保留给桥接。F8 仅暂停 MC 输入；恢复只狼操作请在 MC 执行 `/sekirobridge off`，或关闭 F7 中的 MC player / camera adapter。

MC 自己计算人物位置、速度、重力、跳跃、飞行、走跑动画与方块碰撞；单人服务器只在建立连接时传送一次。原生位置钩子将结果同步给隐藏的只狼角色。相机来自 MC 的实际渲染相机，写入当前只狼 ChrCam 更新结果；MC 的 F5 同时改变两端视图。

MC 的视野设置、疾跑及望远镜缩放继续计算，实际世界视野随帧传递。桥接期间暂时关闭走路摇晃和受伤镜头倾斜，避免这些额外变换与两端相机元数据不一致。

## 必须在游戏内验收的项目

1. **背包**：E 打开；快速连续单击拿起和放下物品、双击收集、右键分堆、拖动、Shift 点击转移、创造搜索。不要仅慢速点击。按钮按下/松开及各自位置应保留，显示的光标应对准实际槽位。不同窗口大小和 Windows 缩放下再检查一次。
   首先确认热栏、准星或背包至少正常显示；F7 中的世界/HUD提交次数分开显示，世界等待深度时不应连 HUD 一起消失。
2. **只剩一套动作**：WASD、跳跃、疾跑、潜行，观察 MC 身体与四肢动画。E 不触发只狼钩锁，鼠标不触发只狼战斗。打开背包时人物应停下；关掉后恢复移动。
3. **视角与重影**：慢转、快速转头、直视上方/下方，F5 三种视角；重点在方块旁左右跑动和连续跳跃。原生场景、MC 图像应配合同一相机，人物轮廓不能残留在上一位置。此同步方式会增加少量统一显示延迟。离线通过不代替实际游戏渲染时序验收。
4. **MC 方块**：手持方块瞄准前方已采样的只狼地面，右键放置第一块，再对 MC 邻面继续放置；也可用 F9 生成起始块。原生斜坡的目标为地面上方完整格，可能不到一格悬空；原生地面不可挖掘。走向 MC 墙、跳上方块、半砖、楼梯和天花板，检查 MC 原版碰撞。
5. **原生地面**：在平地、斜坡、小台阶及悬崖边行走/跳跃/飞行落地。刚连接或进入未知采样范围时，应短暂等待地面数据，然后恢复移动；已确认的空处仍可坠落。`/sekirobridge status` 的 `terrainReady` 表示脚下覆盖是否新鲜。F7 的 MC positions 与 MC camera 计数应增加。原生地面是实验高度场；异常时关闭 adapter，记录当时场景和动作。
6. **释放与重连**：关闭桥接、离开 MC 世界、只狼读图、死亡、切换窗口、调整大小。原角色和输入应恢复；新场景重新从原生位置建立连接，而不是从旧 MC 出生点继续。

## 原生接口和边界

仅支持已校验的本机只狼 1.06。位置写入点、相机尾部和射线函数均检查运行时代码签名。当前 ChrCam 指针还必须与 FieldArea 的相机匹配。未匹配时 MC 控制保持等待，不能退回猜测写地址。

原生射线在玩家物理线程取得附近 9×9 个固定世界格的地面高度，临时加入 MC 本玩家碰撞查询；不在 MC 存档生成屏障。已知地面最多缓存 1500ms，实际新射线未命中立即删除；未知格和已确认空格分别记录，初始化/未知边界暂停本玩家移动和坠落，收到覆盖采样后释放。仅修正不超过阶高的浅穿透，无法从深层虚空自动恢复。仍不完整支持原生垂直墙面、屋顶、悬檐、动态物体及复杂楼层。MC 生物不共享该地面，只狼 NPC 也不会碰撞 MC 方块。跨游戏伤害和战斗尚未接入。

原生接口和真实游戏效果仍需验收，尤其是射线、落地、相机更新时序与快速转头。日志新增 `MC driver cameraCalls`、`controlledMoves`；读取次数不等于功能已经验收。

发布前检查包括：真实 x64 位置/相机 detour 的寄存器恢复、GUI 客户区坐标、完整短点击的跨进程传输、生产输入重放、原版 VoxelShape 穿地反例与恢复、JNI 边界校验、MC 相机/地面包布局、D3D11 遮挡和垂直视角合成、延迟命令列表乱序提交/重放/生命周期、开发及发行 Mixin 目标检查。所有夹具均不运行两款游戏。
