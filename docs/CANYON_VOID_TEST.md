# 峡谷低处虚空误伤验收

只狼峡谷的有效地面可能被转换到 Minecraft 的 `bottomY - 64` 以下。
原版 `Entity.attemptTickInVoid` 仅检查高度，随后由 `LivingEntity.tickInVoid`
造成 4 点 `out_of_world` 伤害；玩家健康账本会把这笔误伤再同步给只狼。

本地修复在该高度检查入口取消**当前桥接角色和原生敌人代理**的 MC 虚空处理。
保护要求桥接仍连接、同一个会话 epoch、同一个客户端或集成服务器世界；
玩家还必须匹配本地玩家 UUID。无需修改 `y_offset`、MC 世界或只狼存档。
原生角色的摔落、真正掉落死亡及复活继续通过原生 HP/死亡状态结算。
普通攻击、MC 落地摔伤、其他玩家/维度以及关闭桥接后的 MC 虚空规则保留。
本次修复不扩展 MC 建造高度，也不更改普通 MC 生物的虚空规则。

离线回归执行缓存中真实的 MC 高度检查、虚空伤害字节码和编译后的取消回调，
重现旧版本的误伤及健康账本回传，再验证低处玩家、原生代理、切换世界、
断连、会话更新及真实受击/死亡。注入点同时检查开发和 remap 后的生产 JAR。

游戏测试：

1. 使用之前会持续扣血的峡谷低处存档，进入生存模式后开启桥接。
2. 先站在安全地面 20 秒，再沿低处地面正常走动，确认没有规律性的虚空扣血或死亡。
3. 受到一次敌人的真实攻击，确认 MC 和只狼仍正常扣血；测试复活是否能恢复。
4. 在安全位置切换关闭/开启桥接，确认控制恢复。普通 MC 世界仍应保留虚空伤害。

测试结果和 GitHub 上传授权由用户确认；离线检查不代替上述实机验收。
