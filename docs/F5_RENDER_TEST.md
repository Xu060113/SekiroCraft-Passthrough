# F5 人物显示与枪械渲染兼容验收

修复已纳入 2026-10-08 用户授权发布的更新。以下步骤用于视角与模组配置变更后的回归，不代表所有场景都已验证。更新保留用户的 MC 模组、按键、Fabric API 和世界。

## 原因和改动

用户安装的 TaCZ 重织版在启用模板缓冲后，主帧缓冲使用 `GL_DEPTH32F_STENCIL8`。旧桥接的 `SimpleFramebuffer` 使用普通深度纹理；同时复制颜色和深度时，两端格式不匹配，OpenGL 拒绝复制，日志反复记录 `Depth formats do not match`。第三人称人物属于世界层，依赖这份深度进行只狼场景遮挡合成；第一人称手部与 HUD 使用独立层。

桥接现在查询源缓冲的实际深度格式，使用同格式的私有捕获纹理；格式在运行中变化时，即使纹理 ID 和分辨率不变也重新创建捕获缓冲。世界颜色、深度和 HUD 仍按原协议分开传递，相机仍与所捕获的画面配对。没有深度或需要多重采样缩放的来源会丢弃该次捕获，不发布旧深度。

`tests/FrameCaptureGl.java` 用隐藏的 OpenGL 窗口直接调用生产复制代码，复现旧格式错误，检查普通深度、24/32 位深度模板、纹理与渲染缓冲、运行时格式切换、缩放、世界/HUD 三个读回平面及 GL 绑定恢复。它不启动 Minecraft 或只狼，也不能替代 F5 在游戏中的验收。

## 实机步骤

1. 保留目前枪械和拔刀剑配置，进入两款游戏并开启桥接。在开阔平地连续按 F5，轮流检查第一人称、背后第三人称和正面第三人称。两种第三人称应显示 MC 人物，第一人称按 MC 原版规则只显示手部。
2. 在三种视角移动、跳跃、转动镜头，拿枪、瞄准和射击，确认人物与方块持续显示；再放一个方块并观察它是否仍在。
3. 开关桥接并再切换视角，检查 F6 菜单、背包点击、R 换弹、鼠标侧键和 M 钩索仍可用。
4. 查看本次 `logs/latest.log`：不应再由桥接复制持续产生 `Depth formats do not match`。如果人物仍消失，请记录发生的视角、所持物品、方块是否仍可见以及是否靠墙；继续核对实际渲染路径。

仍需另行验证贴墙第三人称相机与只狼原生地形的距离裁剪；这次修复不提供完整原生地形网格或多重采样渲染支持。
