# HP 阶段、钩索跑图与生物蛋验收

这版按照用户请求启用简化 Boss 结算：MC 近战、箭、三叉戟、爆炸、魔法和生物攻击使原生血量耗尽（含原生锁在 1 HP 的情况）时，自动结算一个原生红点，无需等待红点提示或按 R。剩余红点恢复血量和姿态，最后一个红点后归零血量。一次命令只结算一个阶段，过期阶段命令被丢弃，阶段和命令编号共同防止重复扣点。

先尝试已校验的原生 type-5 受击路径；若引擎没有扣点，再使用已校验版本的阶段计数位置进行简化结算。只在游戏战斗更新线程、同一实例/句柄/阶段、血量耗尽且非 NoDamage 状态执行。没有改剧情事件或奖励标志；特殊 Boss 换实体、剧情切阶段和最终奖励尚需实机验收，不能把计数归零等同于完成了所有剧情忍杀。

安装时使用 `update-installed.ps1 -Diagnostic -NativeGrappleKey M -AutoBossPhases`。安装器会同时备份两端模组、配置和只狼存档。原版项目不变。

1. 测赤鬼：用 MC 武器打空血量，观察红点 2→1、血量恢复，再打空后 1→0。箭也应该能结算；记录最终死亡/奖励是否出现。
2. 钩索：对准原生可用钩索点，**按住 G 或 M**；保持按住期间可用 WASD、跳跃和原生跑步键跑图。原生绑定为 M。每 300 ms 重新发送一次钩索按键边沿，使恢复地面状态或跳到可钩位置后能再次尝试。松键后，确认动作完成再返回 MC 控制。背包、原生菜单和失焦中不执行接管。狼模型仍隐藏。
3. 生物蛋：在已采样的只狼地面右键使用**僵尸或骷髅蛋**，观察服务端实际生成及地面碰撞；附近只狼敌人应成为其目标。和平难度会移除敌对生物，请先选简单、普通或困难。牛羊等被动生物不会自动攻击。当前不包含只狼 NPC 主动锁定 MC 生物。

离线验证覆盖生产适配器的计数扣减、原生优先/兼容回退、血量和姿态恢复、近战/远程/生物命令、命令去重、阶段隔离和输入接管；两款游戏未由构建脚本启动。实机通过前不应把钩索成功、剧情进度或生物攻击视觉效果记为通过。
