# 桥接下蹲与姿态条开关验收

对应 `v0.1.0-20261010`。用户已进行本轮游戏测试并授权上传，同时反馈受击闪烁仍存在，保留为后续修复项。以下步骤用于持续回归，不代表每种组合均已通过。

## 下蹲

MC 原版在改变姿态前检查目标碰撞箱是否能放入世界。采样的只狼地面轻微侵入脚下时，会使游泳、下蹲、站立检查都失败。仅在桥接玩家的原版姿态检查期间，忽略已经侵入足底、且不超过现有地面恢复上限（最多 0.6 格）的采样地面。移动、放置和投射物仍使用完整采样碰撞，真实 MC 方块与天花板继续参与姿态检查。未强制指定人物姿态或修改按键。

前版实机反馈：视角可识别下蹲，模型仍未正常下蹲；继续修复第三人称动画合成。仅桥接本地玩家的第三人称下蹲先从站立基姿计算武器动画，完成后叠加原版下蹲偏移、同步衣服外层；保留刀剑/枪械的关节旋转与行走，避免重复弯腰。第一人称手部、其他实体以及飞行、游泳、睡眠等姿态保持原路径。

1. 开启桥接，在平地使用非飞行状态，按 F5 切换第三人称，按住 MC 的潜行键。检查身体下蹲、移动减速；松开后站立。
2. 在坡道、台阶附近重复，确认姿态不持续锁在站立、脚下仍有支撑。空手与拔刀剑分别测试。
3. 切换第一人称，检查潜行眼高；在 MC 方块搭建的低天花板下检查原版姿态限制。
4. 创造飞行按潜行键仍为下降。钩索、菜单、过场交接和加载后重新检查动作；关闭桥接后原版 MC 下蹲继续正常。
5. 异常时执行 `/sekirobridge status`，记录 `sneak` 和 `pose`，并描述当时的武器、飞行状态和地面。

## 姿态条开关

这里的耐力条表示只狼姿态值，并非新增体力机制。开关控制 MC 端桥接添加的自己与目标姿态条；只狼原生 UI 不受此选项控制。

- `/sekirobridge stamina`：查询当前显示状态。
- `/sekirobridge stamina off`：隐藏姿态条。
- `/sekirobridge stamina on`：显示姿态条。
- `/sekirobridge stamina toggle`：切换。

默认显示。设置保存在当前 MC 游戏目录的 `sekirobridge/bridge.properties`，键为 `show_posture_hud`。保存时保留共享内存通道、GUI 诊断和其他属性。写入失败会报告错误并保留原开关状态。

1. 在生存模式使姿态条可见，执行 `off`，确认血条、准星、背包和物品栏仍正常，战斗仍可造成姿态变化。
2. 执行 `on` 或 `toggle`，确认立即恢复；用 F1 隐藏/恢复原版界面不会覆盖此开关。
3. 隐藏后正常退出并重启 MC，确认设置保留；`/sekirobridge on` 与 `/sekirobridge hud` 不应强制打开姿态条。
4. `/sekirobridge status` 的 `postureHud` 应与开关一致。

离线回归执行原版 `PlayerEntity.updatePose` 和 `Entity.wouldPoseNotCollide`，覆盖故障复现、下蹲/站立、创造飞行、鞘翅、低天花板、深层穿透和查询作用域清理；另外检查显示偏好持久化、未知配置保留与写入失败。它们不能替代动作与动画模组的实机验收。

## 受击与特效闪烁

只狼敌人命中时人物和方块闪烁的实机问题仍存在，2026-10-10 用户测试后明确要求后续继续修复。本轮补齐非索引、实例、间接及流输出绘制调用的特效前深度保护，记录仅含特效的命令列表；同一相机后续不透明批次保留干净深度，真实清除、相机改变及新帧不沿用旧深度。未改变原生伤害或关闭地形遮挡，不能将这轮改动标为闪烁已解决。

1. 同一敌人连续攻击：第一、第三人称分别观察人物与放置的方块。先空手，再举盾，再持拔刀剑或枪。
2. 在墙前/墙后分别放置方块，移动镜头；确认墙后仍被正确遮挡，没有为了防闪烁而穿墙显示。
3. 传送、过场、F6 菜单及关闭/重新开启桥接后重复。若仍闪烁，记录敌人、攻击类型，以及当时 F7 的 World 状态与 Ignored FX draws 计数，区分特效深度与整帧暂停。

离线 D3D11 回归复现特效污染深度，并验证同一/不同命令列表、后续场景批次与清除边界；不能据此断言所有原生特效已经通过实机验证。不透明且写深度的特殊特效仍需按实际攻击核对。
