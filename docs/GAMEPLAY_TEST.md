# gameplay1 手动验收

同时更新只狼 DLL、MC Fabric JAR 和嵌入 JNI。离线检查通过，助手没有启动游戏。原创项目和原创 DLL 恢复备份保留。

启动两款游戏，进入只狼可活动场景和专用 MC 单人世界，执行 `/sekirobridge on`，切回只狼。已有键位不变。`/sekirobridge status` 新增 audio/combat；F7 新增 Combat adapter、actors、applied/rejected hits。

1. **地面**：在身边平地放置并点燃 TNT，应在原生地面停留直至爆炸；再测僵尸、掉落物、下落沙子、斜坡和 MC 方块边缘。中心刷新约 100ms、完整外圈约 800ms。附近约 6 米之外、多层楼板、悬檐和原生墙顶尚不保证。
2. **音效**：检查脚步、挖掘、放置、生物和 TNT。声音由 MC 后台进程播放；master=0 时桥接临时输出 70%，关闭恢复，主动调整优先。系统混音器仍需允许 MC 出声，实际暂停菜单可暂停音效。
3. **攻击只狼生物**：靠近普通敌人，确认 actors > 0，用 MC 剑、弓和 TNT 分别攻击，观察原生血条下降和 applied hits 增长。目标是约 0.6×1.8 人体代理，尚无各 Boss 精确骨骼/体形。20 点 MC 伤害按该目标最大 HP 换算为一条血，不采用原生武器数值。
4. **怪物蛋**：在原生敌人旁生成僵尸。敌对怪物应选择附近原生敌人并靠近攻击，伤害传回 HP。原生地面没有 MC 寻路节点时使用局部移动；不能自动绕开只狼墙壁或跨原生悬崖。普通动物保持原版行为，原生 NPC 还不会反过来锁定 MC 怪物。
5. **生存血量**：执行 `/gamemode survival`，首次血条比例以只狼 HP 为准，例如 500/1000 → MC 10/20。原生攻击和 MC 受伤/摔伤都应改变两边血量；MC 食物恢复/治疗应传回原生 HP。检查同一伤害不因重复消息反复扣血。吸收血、饥饿、盔甲和姿态未同步。
6. **创造无敌和释放**：切 creative 或 spectator，原生敌人攻击不应降低玩家 HP；此时 MC 仍能伤害原生敌人。切回 survival、关闭桥接或关闭 MC 后恢复玩家原 NoDamage 位，不强行补血，不设置全角色无伤害。
7. **死亡与重连**：MC 死亡传回原生 HP=0，原生死亡反馈到 MC，掉落应留在死亡处。Boss 若保留 NoDeath 可停在 HP=1，不绕过忍杀与阶段脚本。先完成只狼死亡/复活，再完成 MC 重生。关闭桥接不回滚实际伤害或治疗。

仅支持已校验的本机只狼 1.06。NPC 从既有物理回调观察，不做范围遍历；跨进程只传会话 ID。写 HP 前重新校验 WorldChrMan handle、当前实体/模块、HP/maxHP，并调用有精确机器码指纹的 HP setter。

**尚未定位完整 ApplyDamage、受击、姿态、忍杀或伤害奖励接口**。本次接入原生生命 setter，不能将离线通信通过称为完整战斗已经实测。原生 NPC 仍不碰撞 MC 方块，MC 生物仍不读取完整原生墙体。

异常时保存 runtime/passthrough.log、MC logs/latest.log，记录场景、模式、目标类型和 F7 的 actors/applied/rejected 数量。
