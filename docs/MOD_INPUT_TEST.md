# R 换弹与鼠标侧键验收

此前只狼端已经去掉 R 忍杀触发，但 MC 端仍把游戏中的 R 过滤为保留键，
连暂停后恢复按键状态的路径也排除了 R。本地修复取消这两处 R 过滤；
只有 M 继续用于原生钩索。R 使用真实的 `Keyboard.onKey` 回调转发，
不是仅更新 `KeyBinding` 的按住状态，短促点击也可到达模组的事件监听器。
恢复输入时已排队的真实按键事件优先于采样按住状态，避免同一帧新按下的 R 被预先恢复状态吞掉。

鼠标侧键此前缺少 Windows XBUTTON 消息采集，JNI 输入校验也只接受 0–2。
修复增加 XBUTTON1/XBUTTON2 到 GLFW 3/4（MC 设置里的鼠标 4/5）的转发，
并补齐快照状态、丢失释放恢复、菜单/暂停/断连释放和原生输入隔离。
事件序号、GUI 显示代次和坐标校验继续适用，协议结构大小维持 v3。
两端必须使用配套更新。Caps Lock 映射一并补齐，以支持当前枪械实例的瞄准键。

当前用户实例安装的是 TaCZ Refabricated 0.7.1 / forge1.1.8-hotfix2：
其 `ReloadKey.onReloadPress` 监听键盘按下事件，并匹配 R；
其近战动作同时提供 `onMeleeMousePress` 鼠标事件入口。
键位保留用户设置。本修复转发 MC 输入，不修改枪械模组的装弹规则、弹药或武器状态。

实机步骤：

1. 持有枪械并准备对应弹药，先打掉几发，再在只狼窗口按 R，确认开始换弹。
2. 在 MC 控制设置中给支持鼠标绑定的动作（例如枪械近战）绑定鼠标 4 或鼠标 5，
   回到只狼窗口分别短按两个侧键，确认对应动作触发。
3. 打开背包后测试侧键绑定/点击，再回到游戏。按 F8 暂停和恢复输入，
   确认没有卡住的侧键，恢复本身不应制造一次换弹或侧键动作。
4. 确认 M 钩索仍工作，R 不触发只狼攻击或忍杀，F6 仍可操作只狼菜单。

离线回归覆盖真实 Windows 消息解析、JNI 使用的输入包校验、DirectInput
隔离以及生产 InputForwarder 的按下/松开和恢复路径。枪械动画及弹药结算需用户实测。
