# 拔刀剑首次命中与 R 键释放

本地修复针对 SlashBlade: Refabricated `1.20.1-1.4.0-Resharped-1.9.65`。检查本机实际 JAR 的 `TargetSelector.AttackablePredicate`：`friendly_enable=false` 时，首次命中要求目标实现 MC `Monster`。`RevengeAttacker` 标签有一次性的例外，所以原来的中立类型代理在挨过其他攻击后才能被选中。

现在按只狼传来的敌对阵营标记分别创建 `native_enemy` 与 `native_actor`。敌方子类实现 `Monster`，沿用原代理的 damage/applyDamage 和命令确认路径；不额外扣血、伪造伤害/仇恨标签或修改拔刀剑配置。原生阵营变化时更换代理类型；两种代理均只绘制附着的箭，不增加人物模型。友方/中立代理保持原有可被直接攻击的行为，但在关闭拔刀剑友伤时不会因本次修复被当作怪物选入范围攻击。

R 不再提交原生攻击、忍杀或复活，交给 MC 及第三方模组使用。MC 死亡界面按钮的复活请求保留；M 仍仅触发钩索。红花出现后自动忍杀和 MC 忍杀动画尚未实现，现有 HP 耗尽推进 Boss 阶段的选项暂时保留。

离线检查通过原始拔刀剑目标筛选字节码验证：未受伤敌方直接可选；重复筛选与换实例仍可选；原中立代理的受伤例外仅生效一次；PVP、黑名单、玩家乘客和友伤限制保留。验证不会启动两款游戏，也不能代替刀光、幻影剑、锁定和只狼扣血的实机测试。

请在实际使用的 Fabric 实例测试：

1. 重载到一个未受过伤的普通敌人附近，直接用拔刀剑近战、刀光与幻影剑攻击，确认首次攻击便使只狼 HP/姿态变化；不要先用其他武器垫伤害。
2. 换一个未受伤敌人，测试锁定、连击、射程外挥刀；不能因取消 R 后丢失 MC 原有按键。
3. 友方/中立 NPC 附近使用范围攻击，默认关闭友伤时不应因桥接代理的类型而被误选。
4. 普通剑与箭仍可命中，M 钩索正常。按 R 不再启动原生攻击或忍杀；死亡界面的复活按钮仍有效。
5. 测试原生阵营变化、读档、Boss 换阶段和过场恢复，确认不需要预先打伤敌人才能重新锁定。
